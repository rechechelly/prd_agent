# 列表与确认弹窗示例

本例只用于理解章节组织、字段详度和图文对应方式。设备、权益、代金券、国内/海外用户等均是示例业务，不是通用需求。截图文件须由当前原型真实生成，不可照搬这里的文件名后省略截图。原型中只展示的控件必须集中声明。

```html
<h3 id="list">3.1 设备列表</h3>
<figure>
  <img src="assets/devices/01-list.png" alt="设备管理列表，时间列四行，最右为设备重制">
  <figcaption>图 1　设备列表。默认查询为全部，示例 5 条，最右列为「操作」</figcaption>
</figure>
<p class="anno"><strong>标注:</strong> 图 1 和图 2 是同一张列表，「时间」一列里分行写「录入：」「激活：」「绑定：」「最近活跃：」。已绑定的行显示「设备重制」，未绑定的行这一列为空。原型共 5 条、只有第 1 页；正式环境沿用现有分页。查询框在原型中不触发过滤，正式环境沿用线上查询。</p>
<p><strong>页面简述:</strong> 列表同时回答这台硬件是谁、何时录入和激活，以及现在绑的是哪个账号、能否重制这台设备。</p>

<h4>3.1.1 查询区</h4>
<ul>
  <li><strong>需求描述:</strong> 沿用线上查询，本次不新增查询项，也不改默认值。</li>
  <li><strong>内容:</strong> 左侧为「共 N 条数据」，N 为当前结果条数。右侧从左到右是设备 ID、指纹地址、用户、激活状态、绑定状态。</li>
  <li><strong>选项:</strong> 设备 ID 占位文案为「请输入设备 ID」。指纹地址占位文案为「请输入指纹地址」。用户占位文案为「请选择用户」。激活状态、绑定状态的默认文案都是「全部」。</li>
  <li><strong>数据来源:</strong> 条数等于当前查询命中的设备数。原型默认显示「共 5 条数据」。</li>
</ul>

<h4>3.1.2 列表字段</h4>
<ul>
  <li><strong>需求描述:</strong> 原有列继续展示设备本身。新增列展示当前绑定账号，并给出设备重制入口。</li>
  <li><strong>内容:</strong> 列从左到右如下。
    <ul>
      <li>设备 ID：文本。设备编号，例如 moark-c74e58f8。单元格内截断，悬停后可复制全文。</li>
      <li>指纹地址：文本。单元格内截断，悬停后可复制全文。</li>
      <li>设备型号：文本。例如 PocketClaw S10。</li>
      <li>版本号：文本，右对齐。例如 1.0.1。</li>
      <li>时间：四行文本，标签依次为「录入：」「激活：」「绑定：」「最近活跃：」。均精确到分钟，格式 YYYY-MM-DD HH:mm。未绑定时只有「绑定：」显示「—」。</li>
      <li>最近活跃 IP：文本。例如 183.212.164.190。</li>
      <li>用户：文本。国内账号显示为链接，海外账号显示为普通文本。未绑定显示「—」。</li>
      <li>用户类型：枚举，取值为国内或海外。未绑定显示「—」。</li>
      <li>用户联系方式：已绑定时两行，标签为「手机：」「邮箱：」。缺一项时该项显示「—」；未绑定时整格显示「—」，不展示标签。</li>
      <li>操作：已绑定时显示按钮「设备重制」。未绑定不显示按钮。</li>
    </ul>
  </li>
  <li><strong>交互:</strong> 点击国内用户名，在新标签页打开该用户主页。主页内容本次不设计。海外用户名不能点击。</li>
  <li><strong>数据来源:</strong> 用户、用户类型、用户联系方式，以及「时间」里的「绑定：」，读取该设备当前的绑定账号。</li>
</ul>

<h3 id="reset">3.2 设备重制</h3>
<figure>
  <img src="assets/devices/02-reset.png" alt="设备重制确认，说明将解绑、废除已兑换代金券，并恢复为未激活未绑定">
  <figcaption>图 2　设备重制。当前设备 moark-c74e58f8，用户 lin_yuan</figcaption>
</figure>
<p class="anno"><strong>标注:</strong> 确认里没有备注、退货单号或其他输入项。本页不打开代金券流水。原型点击「确认重制」一定会成功；正式环境失败时不改这一行。</p>
<p><strong>页面简述:</strong> 退货之后，运营对这一台已绑定设备确认重制：解除当前用户，废除该用户已兑换的代金券，并把设备恢复为未激活、未绑定。</p>

<h4>3.2.1 确认弹窗</h4>
<ul>
  <li><strong>需求描述:</strong> 点击「设备重制」后先确认，再执行重制。</li>
  <li><strong>内容:</strong> 标题为「设备重制」。说明只有一句，按该行填入设备 ID 和用户名：「确认后将解除设备「{设备 ID}」与用户「{用户名}」的绑定，废除该用户已兑换的代金券，并把设备恢复为未激活、未绑定。」按钮为「取消」和「确认重制」。</li>
  <li><strong>交互:</strong> 点击「取消」、按 Esc、点击遮罩，都关闭弹窗，列表保持打开前的内容。点击「确认重制」后关闭弹窗，该行改为未激活、未绑定，并提示「已重置该设备」。请求返回前「确认重制」不可再次点击。失败时弹窗保持打开，提示「设备重制失败，请稍后重试」。</li>
  <li><strong>逻辑:</strong> 成功后做四件事：解除绑定、作废这次绑定占用的权益、废除该用户已兑换的代金券、把设备恢复为未激活、未绑定。「激活：」「绑定：」改为「—」，其余列保持重制前的值。</li>
</ul>
```
